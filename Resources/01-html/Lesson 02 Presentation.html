Lesson 02

Research and Information Models

Turning facts into useful website content

Today's Lesson

Reliable research for a useful website

Learning Intention

We will gather reliable information and organise it into a simple information model for a one-page website.

Success Criteria

  • Collect useful facts from suitable sources.
  • Record where text and images came from.
  • Describe content using clear characteristics.
  • Explain how a model helps visitors compare information.

Reliable research makes the website more useful for real visitors.

Key Words

Words we will use today

Source

Where information or an image came from.

Reliable

Information that is accurate, trustworthy, and suitable.

Information model

A structured way to describe real-world things using fields.

Characteristic

A detail that describes an item, such as location or category.

Credit

A note showing where text, images, or information came from.

Use these words when explaining how you chose your content.

Research Questions

Before you collect content, check that it is useful

Context

You are researching content for a one-page "Visit Edinburgh" website. Your audience is tourists who want useful trip information quickly.

  • Is the source suitable? Check whether the website is relevant, current, and trustworthy.
  • What fact is useful? Choose information a visitor would actually need.
  • Can I rewrite it? Record facts in your own words.
  • What credit is needed? Save the website name, URL, and image credit.

Good research is not collecting everything. It is choosing what helps the visitor.

Computing Link

Models make information easier to use

Sort by name

Put attractions into alphabetical order so users can scan them quickly.

Sort by category

Group attractions, transport, food, and visitor tips.

Search by location

Find items near the Royal Mile, city centre, or a transport route.

Compare visitor value

Decide which items best match the audience's needs.

Structured information is easier to sort, search, compare, and reuse.

Main Task

Build your research log

  1. Choose at least three attractions or visitor topics.
  2. Find useful facts from suitable sources.
  3. Rewrite each fact in your own words.
  4. Record the source name and URL.
  5. Record image sources or credits.
  6. Complete the model fields for each item.
Support

This section is useful for visitors because...

Challenge

Choose one field that could be used for sorting or searching and explain why.

Check for Understanding

Scenario

You are creating an information model for Edinburgh attractions that tourists could use to compare places quickly.

Choose the level that stretches your thinking

1Beginning to learn
  1. What is an information model?
  2. Name one detail about an attraction.
2Making progress
  1. Give three characteristics.
  2. Put three attractions in alphabetical order.
3Making good progress
  1. Explain one way attractions could be sorted.
  2. Explain one way attractions could be searched.
4Meeting target
  1. Design a model and justify the fields.
  2. Explain how it helps users compare attractions.

Start where you feel confident, then try the next level.
