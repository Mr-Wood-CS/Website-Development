Lesson 03

Building in RocketCake

Turn the plan into the first version of a one-page website.

Today's Lesson

Build the first draft

Learning Intention

We will use RocketCake to build the first version of a one-page website from a plan.

Success Criteria

  • Create and save a new RocketCake project.
  • Add headings, text, images, and content sections.
  • Preview the page and compare it with the plan.
  • Make build decisions that support audience and purpose.

Build one section at a time: heading, image, short paragraph, useful detail.

Key Words

Words we will use today

Visual development tool

Software for arranging page objects rather than writing all code by hand.

Container

A layout area that holds related content.

Preview

Viewing the page as a user would see it.

Draft

An early version that can still be improved.

Consistency

Repeated styles, spacing, and structure.

Use these words when explaining how you built your first version.

RocketCake Tools

Choose the right tool for each part of the page

Context

You are building the first draft of your "Visit Edinburgh" website. Each tool should help you create the page planned in Lesson 01.

  • New project Start a clean file and save it clearly.
  • Text and headings Add the title, introduction, section headings, and paragraphs.
  • Image Insert suitable images that match the researched content.
  • Preview and save Check the page often and save regularly.

The tool is not the goal. The goal is a clear page that matches the plan.

Build Order

Build from the plan, not from memory

  1. Create the project and save it.
  2. Add the page title and short introduction.
  3. Build section 1 from the storyboard.
  4. Build section 2 from the storyboard.
  5. Build section 3 from the storyboard.
  6. Add image credits and source notes.
  7. Preview the whole page.

Following the plan helps your page stay organised.

Good Habits

Small checks stop big problems later

Save often

Save after every major change.

Preview often

Check how the page looks before adding more content.

Use your plan

Build the sections in the order you planned.

Keep spacing consistent

Similar sections should feel like they belong together.

Good builders check as they go.

Main Task

Create the first draft website

  1. Create a new RocketCake project called Visit Edinburgh.
  2. Add the page title and short introduction.
  3. Create at least three content sections from your plan.
  4. Add at least one suitable image.
  5. Preview the page and compare it with your storyboard.
  6. Save the project.
Support

Build one section at a time.

Challenge

Create a consistent section style so the page feels organised.

Check for Understanding

Scenario

You have started building the "Visit Edinburgh" page in RocketCake and need to check that the draft still matches your plan.

  1. Which tool adds text?
  2. Which tool adds images?

  1. Describe how to add a heading and paragraph.
  2. Describe how to place an image.

  1. Explain how layout improves readability.
  2. Explain why consistent spacing matters.
