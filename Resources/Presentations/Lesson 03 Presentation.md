# Lesson 03 Presentation: Building in RocketCake

## Slide 1: Title

**Kicker:** Lesson 03  
**Title:** Building in RocketCake  
**Subtitle:** Turn the plan into the first version of a one-page website.

**Purpose:** Move pupils from planning and research into practical website construction using RocketCake's visual tools.

## Slide 2: Learning Intention and Success Criteria

**Learning intention:**  
We will use RocketCake to build the first version of a one-page website from a plan.

**Success criteria:**
- I can create and save a new RocketCake project.
- I can add headings, text, images, and content sections.
- I can preview my page and compare it with my plan.
- I can make build decisions that support my audience and purpose.

**Footer prompt:**  
Build one section at a time: heading, image, short paragraph, useful detail.

## Slide 3: Key Words

**Kicker:** Key Words  
**Title:** Words we will use today

**Keyword cards:**

**Visual development tool**  
Software that lets you build a page by arranging objects rather than writing all the code by hand.

**Container**  
A layout area that holds related content, such as a heading, image, and paragraph.

**Preview**  
Viewing the page as a user would see it in a browser or preview window.

**Draft**  
An early version of the website that can still be improved.

**Consistency**  
Using repeated styles, spacing, and structure so the page feels organised.

**Footer prompt:**  
Use these words when explaining how you built your first version.

## Slide 4: RocketCake Tools

**Kicker:** RocketCake Tools  
**Title:** Choose the right tool for each part of the page

**Context:**  
You are building the first draft of your "Visit Edinburgh" website. Each tool should help you create the page planned in Lesson 01.

**Question/tool cards:**

**New project**  
Start a clean website file and save it with a clear project name.

**Text and headings**  
Add the title, introduction, section headings, and short visitor-friendly paragraphs.

**Image**  
Insert suitable images that match your researched content and audience.

**Container**  
Group related information so each section feels organised and easy to scan.

**Preview and save**  
Check the page often and save regularly so progress is not lost.

**Side note:**  
The tool is not the goal. The goal is a clear page that matches the plan.

## Slide 5: Build Order

**Kicker:** Build Order  
**Title:** Build from the plan, not from memory

**Suggested order:**
1. Create the project and save it.
2. Add the page title and short introduction.
3. Build section 1 from the storyboard.
4. Build section 2 from the storyboard.
5. Build section 3 from the storyboard.
6. Add image credits and source notes.
7. Preview the whole page.

**Footer prompt:**  
Following the plan helps your page stay organised.

## Slide 6: Good Habits

**Kicker:** Good Habits  
**Title:** Small checks stop big problems later

**Habit cards:**

**Save often**  
Save after every major change so you do not lose work.

**Preview often**  
Check how the page looks before adding more content.

**Use your plan**  
Build the sections in the order you planned.

**Keep spacing consistent**  
Similar sections should feel like they belong to the same website.

**Use meaningful content**  
Text and images should help the visitor, not just fill space.

**Side note:**  
Good builders check as they go.

## Slide 7: Your Task

**Kicker:** Main Task  
**Title:** Create the first draft website

**Task steps:**
1. Create a new RocketCake project called Visit Edinburgh.
2. Add the page title and short introduction.
3. Create at least three content sections from your plan.
4. Add at least one suitable image.
5. Preview the page and compare it with your storyboard.
6. Save the project.

**Support:**  
Build one section at a time: heading, image, short paragraph, useful detail.

**Challenge:**  
Create a consistent section style so the page feels organised.

## Slide 8: Check for Understanding

**Kicker:** Check for Understanding  
**Title:** Choose the level that stretches your thinking

**Scenario:**  
You have started building the "Visit Edinburgh" page in RocketCake and need to check that the draft still matches your plan.

**1 - Beginning to learn**
- Which RocketCake tool adds text?
- Which RocketCake tool adds images?

**2 - Making progress**
- Describe how to add a heading and a paragraph.
- Describe how to place an image in the correct section.

**3 - Making good progress**
- Explain how layout choices can improve readability.
- Explain why consistent spacing matters.

**4 - Meeting target**
- Evaluate your current page against your plan and identify one precise improvement.
- Explain how your build decisions support the target audience.

**Footer prompt:**  
Start where you feel confident, then try the next level.

## Slide 9: Exit Ticket

**Kicker:** Exit Ticket  
**Title:** What did you build today?

**1 - Beginning to learn**  
Name one thing you added today.

**2 - Making progress**  
Name two changes you made today.

**3 - Making good progress**  
Name two changes and explain why they improved your page.

**4 - Meeting target**  
Name two changes, explain why they improved your page, and link each change to audience or purpose.

**Final takeaway:**  
RocketCake helps you build visually, but the plan should still guide every decision.
