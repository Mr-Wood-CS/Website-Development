Lesson 04

Layout, Navigation and Devices

Improve structure, readability, and how the page works for different users.

Today's Lesson

Improve structure and readability

Learning Intention

We will improve the structure and readability of a one-page website and check how it appears on different devices.

Success Criteria

  • Improve headings, spacing, and section order.
  • Explain how layout affects user understanding.
  • Preview the page on different device sizes.
  • Make navigation choices that support the audience.

Good layout helps visitors understand the page quickly.

Key Words

Words we will use today

Heading

A clear label that tells users what a section is about.

Whitespace

Empty space around content that improves readability.

Navigation

How users move through the website or find a section.

Device

The screen used to view the page.

Responsive layout

A layout that adapts for different screens.

Use these words when explaining how your layout helps users.

Structured Information

Headings and sections help users scan the page

Context

Your one-page website has several sections. Visitors should understand each section without reading everything first.

  • Are headings clear? Each heading should tell the user what information comes next.
  • Are sections grouped well? Related text, images, and facts should sit together.
  • Is spacing consistent? Similar sections should have similar spacing.
  • Can users scan quickly? Important information should be easy to find.

Structure makes information easier to understand.

Device Preview

The same webpage can look different on different screens

Phone

Content may stack vertically and images may take up more screen height.

Tablet

Some sections may fit side by side, but spacing still needs checking.

Desktop

There is more horizontal space, but wide text can become harder to read.

Preview

Spot layout problems before users do.

Previewing helps you spot layout problems before users do.

Navigation

One-page websites still need a clear route

Context

Navigation is not only menus. It is also the order and clarity of the page.

  • First section Does it introduce the page clearly?
  • Section order Does it match the visitor's needs?
  • Links Would anchor links or a section menu help?
  • Ending Does the page ending feel complete?

Navigation helps users know where they are and where to go next.

Main Task

Improve the layout and preview the page

  1. Check every section has a clear heading.
  2. Improve spacing between sections.
  3. Make images and text easier to read.
  4. Preview on at least two device sizes.
  5. Improve one part of navigation or section order.
  6. Record what changed and why it helped.
Support

Improve one section first: heading, spacing, and image placement.

Challenge

Compare two devices and justify one improvement.
