Lesson 03 - Building in RocketCake

Learning intention: I can use RocketCake to build the first version of a one-page website.

Success criteria:

  • I can create a new RocketCake project.
  • I can add headings, text, images and sections.
  • I can save and preview my work.

Starter

What is the difference between planning a website and building a website?

Teacher Input

Demonstrate creating a new RocketCake project, adding a title, adding a text block, inserting an image and previewing the page.

Main Task

  1. Create a new RocketCake project called Visit Edinburgh.
  2. Add the page title and short introduction.
  3. Create at least three content sections from your plan.
  4. Add at least one suitable image.
  5. Preview the page and save the project.

Structured Support

Build one section at a time: heading, image, short paragraph, useful detail.

Challenge

Create a consistent section style so the page feels organised.

Exit Ticket

List two RocketCake tools you used today and what they changed on the webpage.
