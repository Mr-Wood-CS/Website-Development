Lesson 05 - Testing, Accessibility and Refinement

Learning intention: I can test a website against requirements and refine it based on evidence.

Success criteria:

  • I can test whether my website meets the brief.
  • I can identify errors or weaknesses.
  • I can make improvements based on feedback.

Starter

What is the difference between a mistake, a missing requirement and an improvement?

Teacher Input

Model testing: check title, section count, images, readability, spelling, links and source credits. Discuss accessibility: contrast, text size, alt text and clear headings.

Main Task

  1. Complete the Test Plan.
  2. Ask a peer to complete the Peer Feedback sheet.
  3. Choose at least three improvements.
  4. Make the improvements in RocketCake.
  5. Record before and after evidence.

Structured Support

Start with the checklist in the Success Criteria file. Fix one issue at a time.

Challenge

Explain one refinement using the words requirement, evidence and user.

Exit Ticket

Name one accessibility improvement and explain who it helps.
