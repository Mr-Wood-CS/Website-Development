Lesson 01 - Planning a One Page Website

Unit: Website Development with RocketCake

Topic: Visit Edinburgh

Learning intention: I can describe the audience, purpose and information structure of a one-page website.

Success criteria:

  • I can identify the audience for a website.
  • I can explain the purpose of a one-page website.
  • I can plan sections that help a visitor find useful information.

Starter

Look at two travel websites. What information appears first? What helps you trust the website?

Teacher Input

Explain audience, purpose and content hierarchy. Show how a one-page website can still have clear sections.

Main Task

  1. Open the Website Brief Template.
  2. Choose the audience for the Visit Edinburgh website.
  3. Choose at least three content sections.
  4. Sketch the order of sections using the Page Plan Storyboard.

Structured Support

Suggested sections: Welcome, Top Attractions, Getting Around, Visitor Tips, Image Credits.

Challenge

Add a reason for each section. Explain how it supports the audience.

Exit Ticket

Write one sentence explaining the difference between audience and purpose.
