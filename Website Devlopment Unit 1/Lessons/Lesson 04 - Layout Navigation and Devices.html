Lesson 04 - Layout, Navigation and Devices

Learning intention: I can improve a website layout so information is easy to read on different devices.

Success criteria:

  • I can explain how layout affects a user's understanding.
  • I can improve spacing, order and readability.
  • I can test how the page may appear on different devices.

Starter

Why might the same webpage look different on a phone and a desktop monitor?

Teacher Input

Discuss structured information in webpages and how visual tools create structure behind the scenes. Introduce navigation within a one-page site.

Main Task

  1. Check the order of your sections.
  2. Improve headings so users can scan the page.
  3. Use RocketCake preview/device tools if available.
  4. Add links or navigation if supported by your version and teacher guidance.
  5. Record two improvements you made.

Structured Support

Use this check: Can I tell what each section is about in three seconds?

Challenge

Explain how a browser, web address, sender, receiver and packets are involved when someone loads your page online.

Exit Ticket

Give one example of the same information represented in two different ways.
