Lesson 06 - Final Assessment and Evaluation

Learning intention: I can present, evaluate and submit a completed one-page website.

Success criteria:

  • I can show how my website meets the requirements.
  • I can explain design decisions using computing vocabulary.
  • I can evaluate strengths and next steps.

Starter

Choose your strongest website feature. Why does it help the audience?

Teacher Input

Review the assessment rubric and model a short evaluation paragraph.

Main Task

  1. Complete final checks using the Success Criteria file.
  2. Export or save the RocketCake project as instructed by your teacher.
  3. Complete the Evaluation Template.
  4. Submit planning, research, testing and final website evidence.

Structured Support

Use the evaluation sentence starters. Refer to the rubric when choosing evidence.

Challenge

Explain how your final website represents structured information and how it might be loaded by a browser over a network.

Exit Ticket

Write one target you would set yourself for the next website project.
