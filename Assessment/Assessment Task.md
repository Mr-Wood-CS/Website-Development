# Assessment Task

## Task

Create a one-page `Visit Edinburgh` website using RocketCake.

## Requirements

- Use RocketCake.
- Create only one webpage.
- Do not write HTML, CSS or JavaScript.
- Include a clear title and introduction.
- Include at least three researched content sections.
- Include suitable images and source notes.
- Make the page readable and organised.
- Test the website against the requirements.
- Improve the website based on testing or peer feedback.
- Complete a final evaluation.

## Evidence to Submit

- Website Brief Template
- Page Plan Storyboard
- Research Log
- Asset Log
- RocketCake project or exported evidence as directed by the teacher
- Test Plan
- Evaluation Template
