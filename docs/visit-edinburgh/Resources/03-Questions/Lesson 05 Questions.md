# Lesson 05 Questions

## Starter Questions (Scaffolded)

### 1 - Begining to learn
1. What is testing?
2. What is accessibility?

### 2 - Making progress
1. Why should someone else test your website?
2. Give one accessibility check.

### 3 - Making Good progress
1. Explain why testing should happen more than once.
2. Explain how feedback can improve a final product.

### 4 - Meeting target
1. Evaluate which test type (readability, links, images, accessibility) is most important for your current draft and justify your answer.
2. Explain how test evidence should influence design decisions.

## Check for Understanding (Scaffolded)

### 1 - Begining to learn
1. Give one test for readability.
2. Give one test for images.

### 2 - Making progress
1. Describe one way to test links.
2. Describe what to do after finding an error.

### 3 - Making Good progress
1. Explain the difference between identifying an issue and fixing an issue.
2. Explain how you would prioritise multiple errors.

### 4 - Meeting target
1. Create a mini test checklist and justify the order.
2. Evaluate one change made from peer feedback and explain its impact.

## Exit Ticket (Scaffolded)

### 1 - Begining to learn
Name one issue you found.

### 2 - Making progress
Name one issue and how you fixed it.

### 3 - Making Good progress
Name one issue, how you fixed it, and how you checked the fix worked.

### 4 - Meeting target
Name one issue, explain your fix, and evaluate how the change improved accessibility or usability.
