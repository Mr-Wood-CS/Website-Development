## :compass: Before You Plan the Page, Plan the Visitor's Journey

When you are designing a website you should always be thinking of the end user and asking:

| Question | What to Think About |
|-----------|-----------|
| Who is it for? | Choose a specific audience, such as families, tourists, students, or first-time visitors. |
| What does the user need? | Think about the visitor's main goal, such as planning a trip, finding attractions, or checking transport. |
| What information comes first? | Put the most useful details near the top so visitors do not have to search for them. |
| What action should the user take? | Decide whether the site guides the visitor to explore, book, contact someone, or plan their route. |

Each question helps you decide what the visitor needs and how the page should be organised.

## :memo: Task One - 20 Minutes

Start at Level One then keep working through the questions.

Challenge yourself to see how far you can go.

=== "Level One"

    **Question 1**

    Who is the audience for the `Visit Edinburgh` website?

    **Question 2**

    What is one purpose of the website?

=== "Level Two"

    **Question 3**

    Name one thing tourists would need to know before visiting Edinburgh.

    **Question 4**

    Name two sections that would help tourists use the website.

=== "Level Three"

    **Question 5**

    Explain why the most useful tourist information should appear near the top of the page.

    **Question 6**

    Describe how clear headings would help visitors find Edinburgh information quickly.

=== "Level Four"

    **Question 7**

    Suggest the best first section for the tourist website and justify your choice.

    **Question 8**

    Explain how your section order supports tourists who need quick trip information.

## :triangular_ruler: Designing a Wireframe

Every website needs a clear journey and before we can start building our website we need to make a template of how it is going to look.

In Web Development this is called a Wireframe.

## :world_map: Example Layout

| Section | Purpose |
|-----------|-----------|
| Title | A strong heading and image to welcome visitors. |
| Introduction | A short overview of what the page is about. |
| Attractions | Key places to visit in Edinburgh. |
| Transport | How to get to and around the city. |
| Visitor tips | Practical advice for a better trip. |
| Credits | Sources, image credits, and extra information. |

## :memo: Task Two - 30 Minutes

Use your answers from Task One to decide the sections, headings, and order of your website.

**Start where you feel confident and when that's completed, try the next level.**

=== "Level One"

    Create a basic wireframe and add sections in an order that mostly makes sense.

=== "Level Two"

    Create a clear wireframe with suitable sections in a sensible order, with notes for headings, text, and images.

=== "Level Three"

    Create a detailed wireframe and add well-chosen sections in a logical order that guides the visitor.

=== "Level Four"

    Create a complete wireframe and add all key sections in the best order, with clear notes so someone else could build the page.

=== "Challenge Question"

    Justify your section order by linking it to the audience's needs.
