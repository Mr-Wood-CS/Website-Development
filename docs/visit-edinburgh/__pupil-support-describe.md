# :material-help-circle-outline: Answering Describe Questions

This page is here to help you answer **describe** questions in Computing Science.

A **describe** question asks you to say what something is like.

---

## :material-format-list-bulleted-type: What Does Describe Mean?

A **describe** question asks you to give details about something.

When you describe, you should:

- Say what it is
- Give important details
- Use clear Computing Science words
- Avoid giving a very short answer

A describe answer does **not always need a reason**. It mainly tells the reader what something is like.

**Possible Describe Sentence Starters**

You could start a describe answer with:

- `A source is...`
- `A reliable website has...`
- `An information model contains...`
- `The source URL shows...`
- `A field stores...`
- `A characteristic is...`

---

=== "Example 1"

    | Part | Example |
    |---|---|
    | Question | **Describe what a source is.** |
    | Weak Answer | A source is a website. |
    | Why This Is Weak | This answer is too short. A source can be a website, but it does not give enough detail. |
    | Better Answer | A source is where information or an image originally came from. It could be a website, map, guide, book, or official page. When building a website, sources are used to collect facts and images that help the visitor. |
    | Why This Is Better | Says what a source is, gives examples of sources, and links the answer to the website task. |

=== "Example 2"

    | Part | Example |
    |---|---|
    | Question | **Describe what an information model is.** |
    | Weak Answer | It is a table. |
    | Why This Is Weak | This answer is partly correct, but it does not explain what the table is used for or what it contains. |
    | Better Answer | An information model is a structured way of organising information about real-world things. It usually uses fields, such as name, location, description, source type, and source URL. Each row stores information about one item, such as one visitor attraction. |
    | Why This Is Better | Says what an information model is, mentions fields, gives examples of fields, and links the answer to the Visit Edinburgh website task. |

=== "Example 3"

    | Part | Example |
    |---|---|
    | Question | **Describe one sign that a website source is trustworthy.** |
    | Weak Answer | It looks good. |
    | Why This Is Weak | This answer is too vague. A website looking good does not always mean the information is reliable. |
    | Better Answer | One sign that a website source is trustworthy is that it belongs to an official organisation, such as a council, museum, visitor attraction, or tourism website. Official websites are more likely to contain accurate and useful information. |
    | Why This Is Better | Gives a clear sign of trustworthiness, gives examples of official organisations, uses the word accurate, and links the answer to tourism research. |

---

## :material-comment-check-outline: Reflection

Before moving on, make sure you can:

- Explain what a describe question is asking you to do
- Give clear details in your answer
- Use Computing Science vocabulary correctly
- Add examples when they help your answer
- Describe what something is like without needing to explain why
