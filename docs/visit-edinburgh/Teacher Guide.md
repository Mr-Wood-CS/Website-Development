# Teacher Guide

## Big Idea

This unit introduces website development through design choices, information structure, audience needs and testing. RocketCake is used so pupils can focus on computational thinking, representation and evaluation without writing code.

## Delivery Notes

- Keep the pupil product to one page.
- Pupils should not hand-code HTML, CSS or JavaScript.
- Model RocketCake tools live: text, images, containers, links, preview and responsive/device view.
- Encourage pupils to cite sources for text and images.
- When discussing mark-up, keep it conceptual: webpages have structure behind the scenes, but pupils are using a visual editor.

## Differentiation

Support:

- provide the section headings in advance
- use the sentence starters in the templates
- reduce required sections from four to three
- pair pupils strategically

Challenge:

- add anchor-style navigation if available in RocketCake
- compare desktop and mobile layout
- improve accessibility with alt text, contrast and readable headings
- explain how browser requests and packets are involved in loading the page

## Misconceptions

- A website and webpage are not always the same. This unit creates one webpage within a website project.
- Images from the internet are not automatically free to use.
- A colourful page is not always a useful page.
- Testing is not just checking whether the page opens. It checks requirements, readability and user needs.
