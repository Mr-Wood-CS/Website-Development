# Scheme of Work: Website Development with RocketCake

Level: Scottish Curriculum for Excellence Third Level  
Length: 6 lessons  
Software: RocketCake  
Final product: One-page `Visit Edinburgh` website  
Coding rule: Pupils do not write HTML, CSS or JavaScript

## Curriculum Links

### TCH 3-13a
Pupils identify how information processes communicate in a website system, including user, browser, web page, image files and links.

### TCH 3-13b
Pupils use an information model to describe the planned website: audience, purpose, content sections, assets and navigation.

### TCH 3-14a
Pupils understand that webpages use structured information and that the same information can be represented in different layouts.

### TCH 3-14b
Pupils describe how web browsers, files, addresses, packets and devices interact when a webpage is viewed.

### TCH 3-15a
Pupils select and use RocketCake tools to design, build, test, evaluate and refine a one-page website against requirements.

## Unit Assessment

Pupils submit:

- completed planning template
- research log with sources
- one-page RocketCake website
- test plan and evidence
- final evaluation

Teacher assessment uses the rubric in `Assessment/Rubric.md`.

## Lesson Sequence

| Lesson | Focus | Main Outcome | Evidence |
|---|---|---|---|
| 1 | What makes a useful website? | Pupils analyse audience, purpose and page structure | Website brief and page plan |
| 2 | Information and research | Pupils gather and organise content for a one-page site | Research log and asset log |
| 3 | Building the first version | Pupils use RocketCake to create page sections and add content | Draft website |
| 4 | Layout, navigation and representation | Pupils improve structure, readability and device suitability | Improved layout and navigation |
| 5 | Testing, accessibility and refinement | Pupils test against requirements and fix issues | Test plan and changes |
| 6 | Final assessment and evaluation | Pupils submit and explain final website decisions | Final site and evaluation |

## Structured Support

All lessons include:

- starter retrieval questions
- teacher explanation prompts
- model answers or success criteria
- guided task steps
- stretch challenge
- exit ticket

Support templates are provided for pupils who need sentence starters, checklists and clearly staged tasks.

## Required Resources

- RocketCake installed
- access to safe web research
- images from permitted sources or school-approved image banks
- the templates in this unit folder
- projector or shared screen for teacher modelling

## Suggested Topic Requirements

The `Visit Edinburgh` page should include at least three of:

- Edinburgh Castle
- Royal Mile
- National Museum of Scotland
- Arthur's Seat
- public transport
- food and family activities
- accessibility information
- safety and visitor tips
