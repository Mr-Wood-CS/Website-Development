# Website Devlopment Unit 1

Six-lesson Third Level Computing Science unit for introducing website development with RocketCake.

Topic: Visit Edinburgh one-page website

The unit is designed for pupils to create a one-page website using RocketCake's drag-and-drop interface. Pupils should not write HTML, CSS or JavaScript. The included lesson HTML files are teacher resource pages only.

## Folder Map

- `Scheme of Work.md` - full six lesson overview
- `Teacher Guide.md` - delivery notes and differentiation
- `Lessons/` - one HTML resource file per lesson
- `Resources/Questions/` - retrieval, discussion and exit questions
- `Resources/Presentations/` - slide-style lesson prompts
- `Templates/` - pupil planning, research, testing and evaluation templates
- `Assessment/` - assessment task, rubric and feedback sheets
- `Images/` - simple classroom visuals and wireframes

## Final Pupil Product

Each pupil or pair creates a one-page RocketCake website called `Visit Edinburgh`. It should include:

- a clear title and purpose
- at least three researched sections
- suitable images with source notes
- navigation links or anchors within the page if supported
- a consistent layout
- accessibility checks
- testing evidence
- a short evaluation
